# 履历引擎 · Career Engine

> 让每一份经历，都成为未来的竞争力。

履历引擎是一款面向大学生与研究生的**个人经历资产库与简历生成工具**。它把散落在笔记、网盘和聊天记录里的项目、竞赛、科研与实习经历统一沉淀下来，再针对不同岗位快速组合成独立简历版本，并导出为 A4 PDF。

本项目为**天池 Qoder 竞赛参赛作品**，是一个可直接运行、构建与部署的完整前端应用。

## 项目简介

求职时，大多数人会遇到三个问题：

1. 经历散落在各处，写简历时想不起来、找不到素材；
2. 每投一个岗位就复制一份简历，改到后面版本混乱；
3. 在线简历工具需要注册登录，个人经历被上传到第三方服务器。

履历引擎用「**经历资产库 → 多版本简历快照 → 投递看板**」的闭环解决这些问题：

- 项目、奖项、实习、科研等经历只录入一次，可被多份简历重复引用；
- 每份简历保存独立内容快照，之后修改经历库不会影响已经投递的版本；
- 所有数据保存在浏览器本地 IndexedDB，无需注册登录，也不会上传服务器；
- 内置三套排版模板与实时 A4 预览，通过浏览器打印即可导出 PDF。

目标用户：正在准备实习、校招、保研或留学申请的大学生与研究生。

## 核心亮点

- **本地优先，隐私友好**：无后端、无账号体系，数据只存在当前浏览器中，支持 JSON 备份与恢复。
- **经历复用**：同一段项目、奖项、实习经历可以被不同岗位的简历反复引用，避免重复录入。
- **快照隔离**：简历保存的是创建时的独立内容副本，经历库后续变化不会破坏已投递版本。
- **面向岗位的版本管理**：为每份简历设置目标岗位，支持复制、搜索与多版本维护。
- **打印级排版**：三套模板、主题色、内容密度、字号与中英文板块标题可调，A4 实时预览。
- **完整求职闭环**：从档案、经历、简历一直管理到投递阶段，工作台汇总完善度、投递分布与近期节点。
- **自动保存**：表单修改后自动写入本地数据库，无需手动点击保存。

## 功能一览

### 1. 工作台 `/`

- 根据时间显示问候语与当天日期；
- 展示项目、奖项、经历、简历数量；
- 档案完善度环形进度与补全建议；
- 最近简历列表与投递进展分布；
- 近期投递节点提醒；
- 空状态引导与一键载入示例数据。

### 2. 个人档案 `/profile`

- 姓名、求职方向、电话、邮箱、城市、个人网站、GitHub / 作品集、个人简介；
- 教育背景：学校、学历、专业、起止时间、GPA、排名、补充说明；
- 专业技能：按分类维护技能组；
- 修改后自动保存，并作为新建简历的基础信息。

### 3. 项目管理 `/projects`

- 项目名称、角色、起止时间、项目简介；
- 成果要点列表（Bullet Points）；
- 技术栈、标签、相关链接；
- 附件上传（作品集、截图、文档等，单文件不超过 6 MB）；
- 支持按项目名称与技术栈搜索。

### 4. 奖项竞赛 `/awards`

- 奖项名称、级别、名次、时间、颁发机构、描述；
- 证书图片或 PDF 上传与预览；
- 按奖项级别筛选。

### 5. 经历管理 `/experiences`

- 经历类型：实习、科研、论文、校园、其他；
- 组织、职位 / 角色、地点、起止时间、描述与成果要点；
- 按经历类型筛选，以时间线形式浏览。

### 6. 简历工坊 `/resumes`

- 从个人档案快速生成简历草稿；
- 新建时选择模板、填写简历名称与目标岗位；
- 简历卡片展示模板、板块数、内容数与更新时间；
- 支持搜索、复制、删除；
- 删除简历时自动解除投递记录中的简历引用。

### 7. 简历编辑器 `/resumes/:id`

- **内容编辑**：
  - 基本信息与个人简介；
  - 板块添加、删除、上移、下移、显示 / 隐藏、自定义标题；
  - 从经历库导入项目、奖项、经历、教育背景与技能，也可手动添加空白条目；
  - 条目内部支持排序、编辑与移除。
- **设计设置**：
  - 三套模板切换；
  - 预设主题色与自定义取色；
  - 宽松 / 紧凑两种内容密度；
  - 字号缩放（约 92%–108%）；
  - 中文 / English 板块标题切换（正文内容保持原文）。
- **实时预览与导出**：
  - 右侧实时渲染 A4 页面；
  - 通过浏览器打印功能导出 PDF；
  - 自动保存并在离开页面前刷新待保存内容。

### 8. 投递管理 `/applications`

- 六阶段看板：意向收藏、已投递、笔试、面试、Offer、已结束；
- 桌面端拖拽卡片切换阶段，移动端可通过卡片底部选择器切换；
- 记录公司、岗位、城市、投递渠道、投递日期、下一步计划与日期、关联简历、备注；
- 顶部统计投递总数、面试中、Offer 与近期节点数量；
- 支持按公司、岗位搜索。

### 9. 数据与备份 `/data`

- 数据概览与本地存储占用；
- 导出完整 JSON 备份（附件以 Base64 内嵌）；
- 导入备份前预览数据量，确认后替换当前数据；
- 一键载入示例数据（追加写入，不覆盖已有记录）；
- 清空所有本地数据（带二次确认）。

## 使用流程

1. **完善档案**：填写基本信息、教育背景与技能，作为所有简历的公共底稿。
2. **录入经历资产**：把项目、奖项、实习与科研经历完整记录下来，附上链接、证书和成果要点。
3. **生成简历**：选择模板创建简历，从经历库挑选内容，针对目标岗位调整顺序与措辞。
4. **导出投递**：实时预览 A4 排版，打印为 PDF；在投递管理里记录每一家公司的进度。
5. **持续迭代**：更新经历库、复制简历做新版本，旧投递版本保持不变。

首次打开时，可在工作台或「数据与备份」中点击**载入示例数据**，快速体验完整流程。

## 技术栈

| 分类 | 技术 | 说明 |
| --- | --- | --- |
| 框架 | Vue 3.5 | Composition API + `<script setup>` |
| 构建 | Vite 7 | 开发服务器与生产构建 |
| 路由 | Vue Router 4 | History 模式，页面级路由 |
| 状态管理 | Pinia 3 | 单一 data store 管理全部业务数据 |
| 样式 | Tailwind CSS 3 + 原生 CSS | 设计变量、组件样式与打印样式 |
| 本地存储 | IndexedDB（`idb` 8） | 浏览器本地数据库 |
| 导出 | 浏览器打印 | A4 打印样式，另存为 PDF |

项目不使用后端服务、数据库服务器或第三方登录，构建产物是纯静态文件。

## 构建与部署

项目使用 `createWebHistory()` 路由，部署时需要将**所有前端路由回退到 `index.html`**，否则刷新 `/resumes`、`/applications` 等子路径会返回 404。

### Nginx 示例

```nginx
server {
    listen 80;
    server_name example.com;

    root /path/to/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}
```

### 其他静态托管

在 Vercel、Netlify、Cloudflare Pages 等平台部署时，将构建命令设为 `npm run build`，输出目录设为 `dist`，并配置 SPA 回退规则。

> 建议部署在域名根路径（`/`）下。若需要部署到子路径，需要同时调整 Vite 的 `base` 与 Vue Router 的 history base。

## 数据与隐私

### 数据存储

所有业务数据保存在当前浏览器的 **IndexedDB** 数据库中：

- 数据库名：`career-engine`
- 版本：`1`
- Object Store：`profile`、`projects`、`awards`、`experiences`、`resumes`、`applications`、`meta`

应用没有后端接口，也不包含任何数据上报逻辑。清除浏览器站点数据、更换浏览器或更换设备后，本地数据不会自动迁移，请通过「数据与备份」导出 JSON 文件进行迁移。

### 备份格式

导出的备份文件大致结构如下：

```json
{
  "app": "career-engine",
  "version": 1,
  "exportedAt": "2026-11-22T08:00:00.000Z",
  "data": {
    "profile": {},
    "projects": [],
    "awards": [],
    "experiences": [],
    "resumes": [],
    "applications": []
  }
}
```

- 文件名格式：`履历引擎-备份-日期.json`
- 项目附件与奖项证书以 Base64 形式内嵌，备份文件可完整迁移；
- 导入时会先做数据规范化与校验，确认后替换当前全部数据。

### 简历快照机制

简历中的板块与条目在创建时从经历库复制为独立副本，并记录来源 ID（`sourceId`）。因此：

- 编辑简历中的条目不会修改经历库；
- 修改或删除经历库中的原始记录，不会影响已经生成的简历；
- 需要同步最新经历时，可在编辑器中重新从经历库导入。

## 简历模板

| 模板 | 名称 | 风格 | 适用场景 |
| --- | --- | --- | --- |
| `minimal` | 素白 | 单栏排版，克制留白 | 通用岗位 |
| `classic` | 雅致 | 衬线标题，经典气质 | 学术 / 研究 |
| `modern` | 双栏 | 左侧栏分区，信息清晰 | 技术 / 产品 |

所有模板共用同一套内容模型，切换模板不会丢失内容。双栏模板会把「教育背景」与「专业技能」放入左侧栏。

### PDF 导出步骤

1. 在简历编辑器中点击「导出 PDF」；
2. 浏览器打开打印对话框；
3. 目标打印机选择「另存为 PDF」；
4. 纸张选择 A4，关闭「页眉和页脚」；
5. 保存即可。

## 常见问题

**数据保存在哪里？会上传吗？**

保存在当前浏览器的 IndexedDB 中，不会上传到任何服务器。

**更换电脑或浏览器后数据还在吗？**

不会自动同步。请先在「数据与备份」导出 JSON 备份，再在新环境中导入。

**为什么修改经历库后，旧简历没有变化？**

这是有意的快照设计。已生成的简历保持投递时的状态，避免历史版本被意外改动；需要更新时在编辑器中重新导入即可。

**可以在无痕模式下使用吗？**

不建议。无痕窗口关闭后可能清除本地数据。

**提示「本地存储暂时不可用」怎么办？**

检查浏览器隐私设置、站点存储权限或剩余磁盘空间，也可以更换浏览器后重试。

**导出的 PDF 有页眉页脚或分页不理想？**

在打印设置中关闭页眉页脚，选择 A4 纸张与合适的缩放比例；可调整简历的「内容密度」和「字号」控制页数。

**示例数据会覆盖我的内容吗？**

不会。示例数据以追加方式写入；如需移除，可使用「清空所有数据」。
